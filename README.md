## 💎 Five Loot Modes

The collection includes five different loot configurations.

### 1. Loot Sanft

- Normal game drop frequency
- 10% Primal targeting
- 10% Ancient targeting

### 2. Loot Abenteuer

- Normal game drop frequency
- 30% Primal targeting
- 10% Ancient targeting

### 3. Loot Uralt Plus

- Normal game drop frequency
- 10% Primal targeting
- 20% Ancient targeting

### 4. Max Loot Mix

- Forces Legendary / Set item categories in the supported drop path
- Approximately one-third Primal targeting

### 5. Max Loot Primal

- Forces Legendary / Set item categories in the supported drop path
- Targets eligible Legendary / Set items as Primal

**⚠️ IMPORTANT: Enable only ONE loot mode at a time.**

The percentages represent the cheat configurations. They are not independently verified statistical drop rates.
